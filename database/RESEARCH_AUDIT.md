# Offline post-PR4 research audit

This is a reproducible research-preparation tool, not a database importer, identity resolver,
rights grant or matching input adapter. It makes no network or DB calls. Use the verified merged
repository and the existing local licensed/research handoff:

    python database/research_audit.py --bundle-root "EXISTING_HANDOFF_ROOT" --output "EXISTING_HANDOFF_ROOT/08_OUTPUTS_APPROVED/post_PR4/research/NEW_RUN"

The output must be a fresh subdirectory of that external approved-research directory and outside
the common public repository, including all worktrees. Existing output and linked/reparse paths are
refused. It verifies six pinned Scento artifacts, preserved brand/media manifest hashes, expected
cohort/accounting, unchanged input/source hashes before publication, then writes only named JSON
artifacts. No credentials, private database dump, image bytes or raw rows are published to Git.

  Country/type claims from the publisher remain separate from research-origin/position claims.

  Original CSV note strings, selected arrays, all ordinals/labels, same-note cross-layer membership

- All15note-illustration candidates receive a uniform audit of recorded identity/license/creator/
  attribution/revision and byte/technical/rights gaps. Filename extensions are hints, not decoded
  MIME evidence. No bytes are acquired or validated and no project use is approved.
- Five existing publisher inspiration leads become a structured blocked evidence queue. Two
  publisher grouping IDs are not two independent sensory sources. No overlap score, verified Dupe
  percentage, usable relation or new pair claim is generated.
- A1479-profile progressive-enrichment index identifies source representation and unresolved
  prerequisites within this pinned export only. Deterministic canonical IDs are importer-derived
  targets, not fresh DB reads. Its eligibility field records no authorization by this research
  process; it does not claim to reread or update a database flag.
