## Shared policies used in every row

- **G-PRIVATE:** verified server session plus genuine immutable initial LOGIN lease, exact accepted scope/action/grant manifest, G-SEC-01/02/03/07/08. No object read before authorization. Local navigation is not a grant. Sign-in can start without an authenticated session but verifies real initial proof before issuing one.
- **G-FIELD:** reviewed canonical identity/edition/meaning, selected observation/materialization, compatible scope, no conflicting choice, current source/field/storage/display/automation rights and safe provenance notice before lookup/filter/page/exposure. Apply again before publication. No real-matching eligibility prerequisite for factual display.
- **U-SAFE:** authorized missing facts remain unknown; note membership remains incomplete with unknown closure. Denied/hidden/malformed/nonexistent/revoked private object references use uniform unavailable. Unauthorized callers never receive an object/field existence hint. No unknown-to-zero/known-empty coercion, family/alias acceptance or canonical promotion.
- **E-SAFE:** fixed POST30-READ-1 safe error class/body; no private IDs/counts/SQL/paths or raw parser echo. Session/view/request generation must still match before rendering. Abort/cancel is local generation invalidation plus server cleanup, not a new IF or rollback claim for a sent mutation.
- **A11Y:** native accessible name/role, visible label/instructions, keyboard operation, logical focus order and status/error announcement; no color-only meaning. Disclosures use expanded state; tabs use labelled tab/tabpanel semantics and focus behavior. Text placeholders have honest accessible text, decorative CSS hidden from assistive technology. No keyboard trap or inaccessible disabled-only explanation.
- **C-PRIVATE:** operational responses/errors no-store/private and request/render-local; no private prefetch, shared/framework/CDN persistent cache, service-worker data/offline cache, localStorage/IndexedDB or raw-value telemetry. Only static non-personal shell assets may be content-hash cached. Clear controlled views on logout/expiry/user switch; cannot erase bytes already received.

## Noninteractive field presentation

Headings and fixed field-state labels do not create an undeclared function. The already authorized `Post30Profile.v1` is the only source for name/brand/concentration/year and Top/Heart/Base/General sections. It carries selected provenance and explicit unknown/incomplete/unavailable states. Missing selected fields or denied notices never trigger raw-source fallback. Note members are perceived/declared olfactory notes, not a chemical formula. No complete pyramid, raw family-to-canonical-family mapping, material alias or General-plus-pyramid materialization is inferred.

A static `matching not enabled` message, null Fit, `Data Confidence not evaluated`, `Pairwise Evidence not queried`, and honest image placeholder are scope disclosures, not calls to matching/capability/media interfaces. No0%similarity, confidence score, review sentiment or direct dupe claim is manufactured. Attribution URLs are inert until an explicit user activation of an authorized safe HTTPS link; no server scraping, automatic fetch or private locator is used. Any allowed external link requires accepted no-referrer/opener policy and a visible destination label.

Initial list loading uses one skeleton/status message without fabricated perfume values. An authorized complete first-page read with zero returned displayable items may say no authorized items available; an upstream denied/unknown/failed contract says unavailable. No global-empty statement, total, hidden count or facets follows from a partial/unknown query. Retrying catalogue/detail is a repeat of its existing read IF through the same bounds/gates; a dedicated new retry control must be bound in a later accepted matrix amendment rather than silently inventing an EL ID.

No media/network/source acquisition or private information was submitted to third parties.
