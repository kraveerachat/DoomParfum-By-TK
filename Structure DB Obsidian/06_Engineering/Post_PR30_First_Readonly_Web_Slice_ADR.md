## Strict proposed read transport: POST30-READ-1

This is a **non-executable contract proposal**, not a schema-library install or amendment to frozen IF registries. It refines later bindings of `IF-CATALOGUE-QUERY-1`, `IF-PROFILE-READ-1`, `IF-AUTH-SESSION-1` and `IF-SESSION-END-1`. `IF-PRINCIPAL-LEASE-1` stays service-only. Exact HTTP paths/method bindings, provider proof schema and framework remain UNSELECTED. All objects are closed: every listed key required unless explicitly optional; reject unknown/duplicate keys, duplicate paths, unknown versions, wrong discriminator, implicit coercion, booleans as integers, nonfinite values, invalid UTF-8 and excessive nesting **before** DB work. No permissive framework defaults or validation payload echo.

Browser-visible request context contains no actor ID, scope ID, database LOGIN, role, SQL, credential, callback or path. Server reconstructs the proposed `RequestContext.v1` from verified proof, session generation, policy and lease. Submitted internal context keys are rejected, not merged.

| Distinct channel | Meaning and first-slice handling |
|---|---|
| Canonical fact | A reviewed selected field projected under accepted identity/edition/meaning; not chemical truth or a raw publisher assertion promoted automatically. |
| Selected observation | Exact immutable supporting observation and review/selection relationship; only authorized minimal provenance appears. |
| Raw evidence | Original source assertion/occurrence; never exposed by these read DTOs or searched as fallback. |
| Unavailable / denied | Denial/held/stale/missing prerequisite remains server-internal; public unavailable does not reveal concealed reason or existence. |

| Matching eligibility | Separate purpose-specific contract, not a factual-display gate or inferred from nonempty notes. Matching is not enabled here. |
| Source rights | Exact current caller/source/field/action/audience evidence, separately enforced before use; no permanent license boolean. |
| Data Confidence | Separate future policy-backed channel; first slice not evaluated, no numeric value. |

Catalogue item's name/brand/concentration/release_year use the same closed field envelope with their corresponding fixed paths. Note member names use the name limit; every other variable-length label, URL, reference and timestamp uses an explicit limit below or the fixed grammar above. No open metadata maps.

Unknown safe-code/message combinations are rejected. Internal exception text is never appended. A failure to produce a bounded successful projection returns temporarily_unavailable, never a truncated success.

## Numeric budget policy POST30-READ-BUDGET-1 — all PROPOSED

| Surface | Exact proposed bound / rejection |
|---|---|
| Read request body | 8192 UTF-8 bytes after transfer decoding; no compressed request body; application/json only; enforce before full parse. Authentication proof has separate maximum below. |
| Request target / headers | Request target 2048 bytes, aggregate request headers 16384 bytes; session cookie/proof 4096 bytes; reject excess before private DB work. No query/identity in access logs. |
| Response | Catalogue JSON at most 65536 UTF-8 bytes; detail JSON at most 131072 bytes; error JSON at most 512 bytes; auth/session public response at most 4096 bytes. Enforce final serialization before first byte, no streaming/truncation fallback; initially no response compression. |
| Page and cursor | Explicit page size 1–20, proposed UI value 10; cursor 0 or 1 token, at most 1024 ASCII bytes, lifetime 60 seconds; at most 128 live cursor handles per session. Cursor is opaque server state or authenticated/encrypted token, never readable embedded private IDs. Bind subject/session/scope/filter/sort/selection snapshot/rights epoch/budget version; invalidate after any binding change. No offset or arbitrary page count. |
| Text | query_text at most 128 Unicode scalar values and 512 UTF-8 bytes; names/publisher at most 256 scalars/1024 bytes; concentration/license label at most 64 scalars/256 bytes; attribution at most 1024 scalars/4096 bytes; safe source/license URL at most 2048 ASCII bytes. Both character and byte caps apply. Reject NUL, surrogates and prohibited controls. Never silently shorten attribution or normalize a raw claim into acceptance. |
| Collections / structure | Detail 1–8 requested fields; catalogue at most 20 items; each note layer at most 64 members, all layers at most 256; one provenance envelope per field; JSON nesting at most 8 containers from root (root=1), at most 8192 value/key nodes. No extra nested raw evidence. Overflow fails closed; no partial note list passed off as full. |
| Numerics / time | Page counts/year only strict JSON integers within the listed bounds; no float, numeric string, boolean or NaN repair. UTC timestamps fixed `YYYY-MM-DDTHH:MM:SSZ` (20 ASCII bytes), server precision projection does not alter stored evidence. No Fit/ratio/price value exists in this slice; future exact rational/decimal transport needs separate contract. |
| Deadline | End-to-end server deadline 5000ms from admitted request; connection acquisition at most 500ms; SQL statement at most 3000ms and lock at most 1000ms, each capped by remaining deadline; idle-in-transaction at most 2000ms for the future adapter. Existing read_profile's 3s/1s are per-statement controls, not proof of a 5s request limit. |
| Concurrency / rate | At most 2 in-flight reads per session and 8 globally in initial single-instance pilot; 30 read requests per rolling 60 seconds per session, rejected before object lookup. Deployment beyond one instance requires shared admission/revocation design; no unbounded queue. |
| Revocation / delivery | Revalidate session/scope/selected-field/rights before lookup and again before atomic publication; final gate at most 100ms before response enqueue or repeat it. If rights deadline is reached or relevant generation changes before enqueue, discard. Cancellation acknowledgement/rollback deadline 1000ms; on uncertainty close/discard physical connection. This bounds controlled publication, not network receipt or retraction of bytes already sent. |

The internal reader's **2097152-byte (2MiB)** JSON bound, 65536-byte observation cap and 512-membership cap are internal adapter controls. They are **not** HTTP budgets, safe public DTOs or performance acceptance. The proposed narrower HTTP limits require their own tests and Owner APP-06 acceptance; no claim that the existing callback transport enforces them.

Return authentication_required (proposed HTTP401) for invalid/missing proof before object work, independent of submitted target. For a valid session, malformed profile IDs, nonexistent IDs, hidden IDs, denied/revoked/expired objects and inaccessible scope share identical unavailable (proposed404), fixed body and privacy headers; do not echo ID or vary validation details. Structural request errors use fixed invalid_request (400) before target lookup; resource limits 413/415, unknown schema406, capacity429, and internal/timeout faults503 use uniform public classes independent of hidden existence. A profile-ID grammar error must not become a target-specific400. Assess timing statistically with controlled workloads; do not claim perfect constant time. Unknown/incomplete states are returned only inside an otherwise authorized projection with metadata permission; they are not ways to enumerate concealed fields.

No persistent/shared operational cache, service worker data cache, offline catalogue, localStorage/IndexedDB query history, prefetched private route data, public SSR/CDN cache, browser-visible credentials or raw telemetry. Use proposed `Cache-Control: no-store, private`; apply equivalent framework/server/client cache policy and no-store errors. Static public shell assets may be content-hash cached if their bytes contain no personal data. Logout/session switch clears controlled render buffers, aborts requests and invalidates generations; in-memory clearing cannot erase screenshots or delivered bytes.
