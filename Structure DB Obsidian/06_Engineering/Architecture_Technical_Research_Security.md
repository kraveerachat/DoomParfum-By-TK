## Decision linkage

S-SEC-01–07 support retaining genuine subject identity, reviewing effective privilege chains and treating read snapshots as bounded observations. S-SEC-08–10 support object/action gates and explicit session lifecycle. S-SEC-11 supports the conservative cache matrix and its remote-erasure limitation. S-SEC-12 separates persistent container storage from application permissions. S-SEC-13 prevents conflating project denial with unilateral revocation of a compliant CC license.

These are design constraints, not a claim that PostgreSQL 18, an auth provider, HTTP stack, Docker storage or an offline runtime is installed/configured. A later accepted stack ADR and version-specific implementation tests remain required. See [[Authorization_and_Trust_Boundaries]], [[Data_and_Media_Lifecycle_Architecture]] and [[Cache_Offline_and_Privacy_Policy]].
